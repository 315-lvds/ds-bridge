# 深桥导入 / DeepSeek Bridge Import

把浏览器扩展「深桥导出」生成的 dsbridge v2 JSON，或 DeepSeek 官方导出的 `deepseek_data-*.zip`，筛选后按每批最多 50 个会话导入为 DSH 原生会话；导入过程中可随时停止、暂停或撤销本次已导入的会话。

- 当前版本：**0.2.4**
- 目标适配：**DSH 0.2.2-rc.5**
- 运行时依赖：DSH 内置实验性插件「DeepSeek 会话导入」
- 许可证：Apache-2.0（[LICENSE](LICENSE) / [NOTICE](NOTICE)）

## 这个插件做什么

DeepSeek 官方导出包包含全部会话，官方导入器又只能整包上传、单次最多 1000 个会话。本插件把「选择」和「写入」拆开：

1. 在浏览器中懒加载并解析官方 zip 或深桥 JSON，只保留会话元数据和当前链；
2. 在插件弹窗里按标题、轮次、更新时间、思考过程筛选并勾选；
3. 每批最多 50 个会话组装成官方 v3 zip，POST 到本机 DSH 的上传路由；
4. 逐批写入并汇总结果；可随时停止，选择暂停、保留或撤销。

写入后就是 DSH 原生会话，可以继续对话；本插件不修改 DSH 核心，也不自己实现 v4 持久化。

## 安装

在 DSH 的 Plugins > Add plugin 中选择本目录（`dsh-plugin`），或在 profile 的 `package.json` 中链接本目录。

安装或升级后请**完全退出并重新打开 DSH 桌面应用**，让新的 client bundle 和 locale 生效；只刷新页面可能仍使用旧缓存。首次使用前确认实验性插件「DeepSeek 会话导入」已启用。

## 使用

1. 选择或拖入一个/多个 `.json`、「深桥导出」生成的 zip，或官方 `deepseek_data-*.zip`；插件在本地解析并列出其中每个会话/链。
2. 按标题/ID/文件名搜索，按最少用户轮次、更新时间范围（不限/3/7/14/30 天/自定义）、是否含思考过程筛选，勾选要导入的项。默认不勾选；一次选择超过 50 个会话会弹出 DSH 原生确认框。
3. 用工作区选择器选择目标工作区，点击「开始导入」；插件按每批最多 50 个会话组装并上传，导入中可点「停止导入」。停止在当前批次（最多 50 个会话）处理完后生效，然后选择暂停并继续、保留已导入会话，或归档撤销本次已确认写入的会话。

## 插件详情页

DSH 0.2.2-rc.5 把 locale 里的 `meta.detail` 解释为**插件包内的 Markdown 文件路径**，而不是一段描述文本。本插件不再在 `meta.detail` 放长文本，改为省略该字段，由 DSH 回退读取本 README 作为详情页内容。

因此插件详情页不会出现「插件声明的详细介绍文件无效」；版本、适配、依赖和使用说明都以本页为准。

## 导入规则与限制

- **官方 zip**：按 `chat_session_index.json` 列出会话，按 `current_message_id` 沿 `parent_id` 回溯当前链；没有 `current_message_id` 时取最大数字消息 id。只导入当前链，不导入其它重新生成分支。
- **深桥 JSON**：导入文件里已经线性化的链；全部分支模式下，每条根→叶链是独立 JSON。
- **分批上传**：每批最多 50 个会话或 64 MiB，避免官方导入器单次 1000 个会话上限，也避免一次启动过多 HTTP 请求。停止最多等待当前批次；单个会话仍受服务端 512 MiB 请求体上限约束。
- **附件**：不携带附件字节；图片/文件以无字节的 FILE 片段保留，避免引用不存在的 `export_path`。
- **重复导入**：DSH 不会按源会话 id 去重；同一会话重复导入会生成新的 DSH 会话。重试前请先看清已完成的批次。
- **失败可见**：单个会话构建失败会记录到结果面板，不会静默少导。
- **停止与撤销**：停止在当前批次处理完后生效；撤销会归档本次已确认写入的会话，不删除原始导出文件。若某批在服务器返回前中断，该批中已写入的会话可能没有记录（最多 50 个），需要手动归档。暂停从下一个未处理批次继续，不会重复已完成的批次。
- 解析 300 MiB 级官方 zip 时只按需读取中央目录和选中会话，不把整包解压到内存；但浏览器仍需处理 index 和选中的会话。

## 依赖

本插件复用 DSH 自带的实验性插件 **DeepSeek 会话导入** 的上传路由（`/api/deepseek-chat-import/archive`）写入 v4 会话。若该插件未启用，导入时会提示先在 Plugins > 更多 > 实验性插件中启用它。插件本身只提供客户端 bundle 和筛选/转换逻辑，Host 侧 `apply()` 为空。

## 隐私

解析、筛选与 v3 zip 组装都在浏览器内存完成；只有选中会话的 v3 zip 会 POST 到本机同源的 DSH 路由，不访问外部网络，不读取登录令牌，也不把聊天内容写入日志或 `chrome.storage`。

## 开发说明

本插件在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 中开发，并使用 **DeepSeek V4 Flash** 辅助编写代码、测试与文档；需求、设计、安全边界、验收与发布由维护者负责。二者是开发工具，不是本插件的运行时依赖。
